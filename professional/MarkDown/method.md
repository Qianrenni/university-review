以下是 Markdown 的完整语法示例，涵盖了常见的 Markdown 用法。Markdown 是一种轻量级的标记语言，广泛用于编写文档、博客、README 文件等。

```markdown
# 标题

## 一级标题
### 二级标题
#### 三级标题
##### 四级标题
###### 五级标题
####### 六级标题

---

# 代码

## 行内代码
使用 `print("Hello, World!")` 输出 "Hello, World!"。

## 代码块
```python
def greet(name):
    print(f"Hello, {name}!")

greet("World")
```

支持多种语言高亮，例如：
```javascript
function add(a, b) {
    return a + b;
}
```

# 转义字符

如果需要显示特殊字符，可以使用反斜杠 `\` 进行转义：

- 显示星号：`\*`
- 显示反斜杠：`\\`

# HTML 支持

Markdown 支持嵌入 HTML 标签：

<div style="color: red;">这是一个红色的文字。</div>

---

# 注脚

这是一个带有注脚的文本[^1]。

[^1]: 这是注脚的内容。

---

# 目录生成（TOC）

虽然标准 Markdown 不支持自动生成目录，但许多 Markdown 编辑器（如 Typora）支持以下语法：

```markdown
[TOC]
```

---

# 数学公式（LaTeX）

某些 Markdown 解析器（如 GitHub 不支持，但 Typora 和部分平台支持）允许使用 LaTeX 语法编写数学公式：

- 行内公式：`$E = mc^2$`
- 独立公式：
  ```latex
  $$
  \int_a^b f(x)dx
  $$
  ```
