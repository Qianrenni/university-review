# University Review - 大学知识复习

这是一个系统性的大学知识复习仓库，涵盖了计算机科学、数学、算法等多个领域的知识点。

## 📚 目录结构

### 1. 专业知识 (professional/)

#### 编程语言
- [Java](professional/Java/) - Java语言核心概念、面向对象编程、集合框架等
- [Python](professional/Python/) - Python基础语法、高级特性、常用库
- [C/C++](professional/C/, professional/CPlus/) - C/C++语言基础、内存管理、指针等
- [Go](professional/Golang/) - Go语言特性、并发编程、标准库
- [JavaScript](professional/JavaScript/) - JavaScript核心概念、DOM操作、异步编程
- [TypeScript](professional/TypeScript/) - TypeScript类型系统、高级特性

#### 前端技术
- [Vue.js](professional/Vue/) - Vue框架核心概念、组件化开发、状态管理
- [HTML/CSS](professional/front-back-end-structure/) - 前端基础、响应式设计

#### 后端技术
- [Redis](professional/redis/) - Redis数据结构、持久化、集群
- [Docker](professional/Docker/) - 容器化技术、镜像管理、部署
- [Maven](professional/Maven/) - 项目构建、依赖管理
- [npm/pnpm](professional/npm/, professional/Pnpm/) - Node.js包管理工具

#### 数据库
- [DataBase](professional/DataBase/) - SQL语言、数据库设计、事务处理

#### 操作系统与网络
- [OperatingSystem](professional/OperatingSystem/) - 进程管理、内存管理、文件系统
- [ComputerNetwork](professional/ComputerNetwork/) - TCP/IP协议、HTTP协议、网络安全

#### 算法与数据结构
- [Algorithm](professional/Algorithm/) - 
  - 排序算法（冒泡、选择、插入、快速、归并、堆排序等）
  - 搜索算法（二分查找、DFS、BFS）
  - 动态规划（背包问题、最长公共子序列等）
  - 图算法（最短路径、最小生成树）
  - 字符串算法（KMP、AC自动机）
  - 高级数据结构（线段树、树状数组、红黑树）

#### 人工智能与机器学习
- [Deep Learning](professional/deeplearing/) - 
  - 神经网络基础
  - CNN、RNN、Transformer
  - GAN、GCN等高级模型
  - 注意力机制
- [PyTorch](professional/Pytorch/) - PyTorch框架使用、张量操作、模型训练
- [强化学习](professional/Enhance-Learning/) - Q-learning、策略梯度、Actor-Critic

#### 分布式系统
- [DistributedSystem](professional/DistributedSystem/) - 分布式理论、一致性协议、微服务架构
- [CloudService](professional/CloudService/) - 云计算基础、服务模式

#### 其他技术
- [MobileApplicationDevelopment](professional/MobileApplicationDevelopment/) - 移动应用开发基础
- [SoftwareEngineering](professional/Softare/) - 软件工程原理、设计模式
- [JUnit](professional/Junit/) - Java单元测试
- [LaTeX](professional/Latex/) - LaTeX文档排版
- [Markdown](professional/MarkDown/) - Markdown语法

#### 数学基础
- [Linear Algebra](professional/linear-algebra/) - 线性代数核心概念、矩阵运算
- [Image Processing](professional/Image/) - 图像处理基础
